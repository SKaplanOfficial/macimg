# macimg Changelog

## macimg 0.0.4 - 2025-07-15

- Migrate project configuration from setup.cfg to pyproject.toml as specified in [PEP 621](https://peps.python.org/pep-0621/).

## macimg 0.0.3 - 2023-03-02

- Added core logic for generating new images via the CoreImage interface.

## macimg 0.0.2 - 2023-01-04

- Add 20 new filters.
- Reduce PyObjC dependencies from all packages to only AppKit and Quartz.

## macimg 0.0.1 - 2022-12-27

- Initial version.
- Add core logic for applying image filters and distortions.
- Add core logic for applying geometric transformations to images.
